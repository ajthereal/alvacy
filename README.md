# alvacy

Website for the Body Signal Check (Cek Sinyal Badan), served by GitHub Pages at https://alvacy.com

- `index.html` — landing page + 30-question quiz (ID/EN). Coach links: add `#code` (e.g. `#aj`); coaches are configured in the `COACHES` object near the top of the script.
- `images/` — coach photos and other images.
- `CNAME` — custom domain for GitHub Pages.
